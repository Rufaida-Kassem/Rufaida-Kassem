### 🚀 Featured projects

| Project | What it is | Stack |
| ------- | ---------- | ----- |
| [**Video Background Changer**](https://github.com/Rufaida-Kassem/background_changer) · [live demo](https://background-changer.streamlit.app/) · [model](https://huggingface.co/rufaidakassem/unet_background_segmentation) | Replaces the background of photos and videos using a U-Net (ImageNet-pretrained ResNet-34) I fine-tuned for person segmentation, reaching 0.93 validation IoU. Team project. | Python, scikit-learn, XGBoost, LightGBM, MLflow, Streamlit |
